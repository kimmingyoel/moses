# 모세(Moses) — 영수증 기반 더치페이 서비스

## 서비스 개요

모세(Moses)는 영수증 이미지를 업로드하면 AI가 항목을 자동으로 인식하고, 구성원별로 비용을 직관적으로 배분할 수 있는 스마트 더치페이 정산 서비스입니다.

---

## 서비스 플로우

**1단계 — 영수증 업로드**
한 장 또는 여러 장의 영수증 이미지를 업로드합니다. 업로드 즉시 OCR이 백그라운드에서 시작됩니다.

**2단계 — 구성원 추가** *(OCR 진행 중)*
OCR이 처리되는 동안 함께 정산할 멤버 이름을 추가합니다. 하단 배너에 OCR 진행 상태가 실시간으로 표시되며, 인식이 완료되기 전까지는 다음 단계로 넘어갈 수 없습니다.

**3단계 — 영수증 검토 및 편집** *(OCR 완료 후)*
추출된 항목 목록을 확인하고, 잘못 인식된 항목명·수량·단가·총액을 직접 수정합니다. 각 항목은 **항목명 / 수량 / 단가 / 총액** 구조로 표시됩니다.

**4단계 — 항목 배분**
구성원을 선택한 뒤 항목을 탭/체크하는 방식으로 각자 부담할 항목을 지정합니다. 수량 단위로 배분되며, 모든 항목이 배분 완료되어야 정산 완료 버튼이 활성화됩니다.

**5단계 — 정산 결과 확인**
구성원별 최종 부담 금액이 표시됩니다. 상세 보기를 열면 각 구성원에게 배분된 항목 목록을 확인할 수 있으며, 결과를 클립보드에 복사해 단체 채팅방에 바로 공유할 수 있습니다.

---

## 확정 스펙

**영수증 인식**
- 한국 영수증 전반 지원 (OCR 역량 의존)
- 항목 구조: 항목명 / 수량 / 단가 / 총액
- 인식 후 항목 확인 화면에서 모든 필드 직접 수정 가능
- 부가세·봉사료 별도 처리 없음
- 할인 처리는 추후 결정

**항목 배분**
- 수량 단위로 구성원에게 1:1 배분 (비율 배분 없음)
- 균등 분할 시 반올림 처리, 1원 단위까지 표시
- "전체 균등 배분" 원클릭 버튼 제공
- 모든 항목이 배분 완료되어야 정산 완료 버튼 활성화

**구성원**
- 이름 텍스트 입력만, 연락처 연동 없음
- 최대 20명

**정산 결과**
- 각 구성원의 최종 부담 금액 표시
- 상세 보기: 구성원별 배분된 항목 목록
- 결과 클립보드 복사 → 단체 채팅방 공유용

**서비스 구조**
- 비로그인, 웹 기반
- 정산 내역은 사용자 기기(로컬 스토리지)에 저장
- 총무가 대표 결제 후 나머지 정산하는 구조

---

## 기존 방식과의 차이

| 기존 더치페이 | 모세 |
|---|---|
| 총무가 수기로 항목 분류 | OCR로 항목 자동 추출 |
| N분의 1 균등 분할이 기본 | 항목 단위 개인별 배분 가능 |
| 계산 착오 발생 가능성 | 자동 합산으로 오류 없음 |
| 카카오페이 등 별도 앱 의존 | 영수증부터 정산까지 원스톱 처리 |
